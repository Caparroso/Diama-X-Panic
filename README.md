# Diama × Panic — 3D Room

Experiencia web 3D para visualizar los modelos de Kameo, Kalus, Dragon, la Luna de Majora's Mask y Diama en una sala oscura con iluminación configurable.

## Subir a GitHub

1. Extrae este archivo RAR.
2. Crea un repositorio nuevo en GitHub.
3. Sube todo el contenido de la carpeta `diama-x-panic` a la raíz del repositorio.
4. Para publicarlo con GitHub Pages, abre **Settings → Pages**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/ (root)`.

No requiere instalación ni compilación. Para probarlo localmente, sirve la carpeta con cualquier servidor web estático; abrir `index.html` directamente puede impedir que el navegador cargue los modelos 3D.
